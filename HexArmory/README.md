# HexArmory

Adds custom armor and items to Valheim, expanding progression with new gear and unique effects.

---

## Features

- Adds new custom capes and armor pieces  
- Built using Jotunn for safe, compatible prefab registration  
- Uses vanilla items and crafting stations for balanced progression  
- Fully supports crafting, dropping, pickup, and persistence  
- Designed with multiplayer compatibility in mind  

---

## Current Items

### Tempered Feather Cape
- Based on the vanilla Feather Cape  
- Removes the fire weakness  
- Retains slow fall (Feather Fall) effect  

### Ashen Wingmantle Cape
- Based on the Ash Cape  
- Overrides equip effect with Feather Fall  
- Designed as a stronger late-game cape variant

## Multiplayer

- Recommended: install on **both server and all clients**  
- If not installed on the server:
  - Items may not be available or may not persist correctly  
- If not installed on clients:
  - Items may not render or behave correctly  

👉 Best experience: everyone has the mod installed.

---

## Requirements

- BepInExPack Valheim  
- Jotunn  

---

## Installation

Install with Thunderstore Mod Manager or r2modman.

### Manual Installation

Place `HexArmory.dll` into: `Valheim/BepInEx/plugins/`


⚠️ When creating a zip for manual install or Thunderstore:
- The contents of the zip must be at the root  
- Do **not** zip a parent folder (this causes issues in r2modman)

---

## Notes

- Items are added as new prefabs and do not modify vanilla items  
- Safe to add to an existing world  
- Removing the mod will leave custom items unavailable (they will not disappear, but may not function correctly)
